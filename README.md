# JIHC Portal (my.jihc.edu.kz)

Жамбыл инновациялық жоғары колледжінің ішкі академиялық порталы: сабақ кестесі, электронды журнал (қатысу + 100 балдық баға), медициналық анықтамалар, силлабус модерациясы, кабинет/акт залын брондау, хабарландырулар, ережелер және басшылыққа арналған аналитика.

**Стек:** Next.js 15 (App Router, Server Actions) · Tailwind CSS 4 · Prisma 6 + PostgreSQL · NextAuth (Google @jihc.edu.kz, ата-ана үшін ЖСН/Parent ID + PIN).

## Рөлдер

| Рөл | Бөлім | Мүмкіндіктер |
|---|---|---|
| Студент | `/student` | кесте, бағалар журналы, анықтама жүктеу (PDF/PNG/JPG ≤ 5 МБ), семестрлік рефлексия кураторға |
| Мұғалім | `/teacher` | кесте, журнал (қатысу + баға), силлабус, брондау, топқа хабарландыру, өзі жауапты бөлмелердің өтінімдерін бекіту |
| Куратор (топқа тағайындалған мұғалім) | `/teacher/curator` | топ шолуы («Назар керек»), студент профилі, ата-ана, байланыс журналы мен келісімдер, куратор циклы, іс-шаралар мен тәрбие жоспары, жетістік/кітап/тест, нұсқаулықтар |
| Завуч | `/teacher` + `/academic-director` | кесте генераторы (топ/мұғалім/аудитория қақтығысы), анықтама мен силлабус модерациясы, ата-ана PIN-кодтарын шығару, топқа куратор тағайындау, қорытынды бағалар (Smart Nation «Қорытындылар») және олардың формуласы, ережелер, статистика |
| Директор | `/director` + барлық басқару беттері | Executive dashboard, пайдаланушылар |
| Ата-ана | `/parent` | баласының кестесі мен үлгерімі (тек қарау) |

## Негізгі ережелер

- Қоңырау кестесі `src/lib/bells.ts` ішінде: 11 × 45 минут, 8:30–17:50, дүйсенбі–жұма. Сабақ бірнеше қоңырауды алуы мүмкін.
- Бағалар 100 балдық шкаламен сақталады; 5 балдық бағаға және GPA-ға (4.0) `src/lib/grades.ts` аударады.
- Расталған медициналық анықтама сол күндердегі «Жоқ» белгілерін «Себепті» етеді.
- Брондау: бос кәдімгі кабинет бірден расталады. Акт залы, компьютер кабинеттері және мұғалімдер бөлмесі бөлменің жауапты мұғаліміне (болмаса завучқа) барады. Завуч пен директордың брондауы бірден расталады.
- Куратор бөлімі мұғалімге завуч оны топқа куратор етіп тағайындағанда ғана көрінеді. Куратор жазбалары тек сол куратордың өзіне көрінеді; психологтың құпия тест нәтижелері мен денсаулық диагноздары сақталмайды.
- Google арқылы тек `@jihc.edu.kz` поштасы және жүйеде бұрыннан бар пайдаланушы кіре алады (аккаунттарды әкімшілік енгізеді).

## Қорытындылар (жартыжылдық, жылдық, емтихан)

Smart Nation «Қорытындылар» бетінің баламасы: `/academic-director/results` (завуч, директор) және `/teacher/curator/results` (куратор, тек қарау). Әр пән бойынша 1- және 2-жартыжылдық, жылдық және емтихан бағалары, жартыжылдар бойынша жіберілген сағаттар (барлығы / себепсіз), Excel (.xlsx) экспорт. Студент пен ата-ана ағымдағы жылдың қорытындыларын бағалар бетінде көреді.

- Бағалар журналдан формула бойынша есептеледі (`src/lib/results.ts`). Smart Nation формуласы жарияланбаған, сондықтан оны завуч `/academic-director/results/settings` бетінде қояды: жартыжылдық баға (барлық бағалардың салмақты орташасы немесе категория үлестері), жартыжылдықтардың және емтиханның жылдық бағадағы үлесі, дөңгелектеу, өту шегі. Әдепкісі: EduPage «Среднее» сияқты салмақты орташа, жылдық = екі жартыжылдықтың орташасы, бүтінге дөңгелектеу.
- «Қорытындыны бекіту» есептелген бағаларды `FinalGrade` кестесіне сақтайды: кейін журнал өзгерсе де, қорытынды өзгермейді (өзгерген ұяшық сары жиекпен белгіленеді). «Қайта есептеу» бекітуді алады. Завуч кез келген ұяшыққа баға жаза алады (мысалы емтихан ведомосінен), ол қолмен енгізілген болып сақталады.
- Журнал, бағалар кітабы, студент беті және статистика ағымдағы оқу жылын ғана көрсетеді (1 тамыздан). Өткен жылдар «Қорытындылар» бетінде.

## Жергілікті іске қосу

```bash
cp .env.example .env          # DATABASE_URL, NEXTAUTH_SECRET, т.б.
npm install
npx prisma migrate deploy
npm run db:seed               # демо деректер (ойдан құралған адамдар)
npm run dev
```

`DEMO_LOGIN="true"` болса, кіру бетінде әр рөлге бір батырмамен кіруге болады. Демо ата-ана: ЖСН `070512600123`, PIN `1234`.

## Нақты деректерді EduPage-тен жүктеу

Демо seed орнына колледждің нақты деректерін (мұғалімдер, топтар мен кураторлар, студенттер, пәндер, кабинеттер, сабақ кестесі) EduPage-тен алуға болады. Ресми API жоқ, сондықтан EduPage-ке кірген браузерден үш JSON алынады:

- `regulartt.json`: `POST /timetable/server/regulartt.js?__func=regularttGetData`, body `{"__args":[null,"<кесте нөмірі>"],"__gsh":"00000000"}` (кесте нөмірі `ttviewer.js?__func=getTTViewerData` жауабында).
- `userhome.json`: `/user/` бетіндегі `userhome({...})` аргументі (`dbi` ішінде мұғалімдер мен студенттер).
- немесе екеуі бір `bundle.json` ішінде: `{ "regulartt": ..., "userhome": ... }`.

Файлдарды `data/edupage/` папкасына салыңыз (ол `.gitignore` ішінде: жеке деректерді git-ке салмаңыз), содан кейін:

```bash
npx prisma migrate deploy
npm run db:import:edupage -- data/edupage --dry-run   # тек сандарын көрсетеді
npm run db:import:edupage -- data/edupage --prune     # импорт + EduPage-те жоқ сабақтарды өшіру
```

Қайта іске қосуға болады: жазбалар `edupageId` арқылы жаңартылады. Порталда өзгертілген өрістер (рөл, пошта, ЖСН, бөлме түрі, куратор, Smart Nation коды) қайта жазылмайды. EduPage-те поштасы жоқ, сондықтан мұғалімдер мен студенттер Google арқылы кіруі үшін әкімші олардың `@jihc.edu.kz` поштасын енгізуі керек. Кабинет түрлерін (акт залы, компьютер кабинеті, мұғалімдер бөлмесі) де әкімші белгілейді. Нақты дерекқорда `npm run db:seed` іске қоспаңыз: ол барлық деректі өшіріп, демо адамдарды жазады.

## Колледж серверіне орнату (Docker)

```bash
cp .env.example .env          # NEXTAUTH_URL=https://my.jihc.edu.kz, NEXTAUTH_SECRET, GOOGLE_*, POSTGRES_PASSWORD
docker compose up -d --build  # PostgreSQL + қосымша, миграциялар өзі қолданылады
```

Жүктелген файлдар `uploads` томында сақталады (`src/lib/storage.ts`). Алдына nginx/Caddy қойып HTTPS қосыңыз.

Google OAuth: Google Cloud Console → Credentials → OAuth client (Web). Redirect URI: `https://my.jihc.edu.kz/api/auth/callback/google`.
